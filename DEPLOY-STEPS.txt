STEPS:

4. Click on "package.json" → Delete it

STEPS:

PART A - Push to GitHub:
1. Go to: https://github.com/new
2. Repository name: chain-reaction-game
3. Make it Public
4. DON'T check "Add README"
5. Click "Create repository"
6. Copy the commands shown, or use these:

   In your terminal, run:
   git remote add origin https://github.com/YOUR-USERNAME/chain-reaction-game.git
   git branch -M main
   git push -u origin main

   (Replace YOUR-USERNAME with your actual GitHub username)

PART B - Deploy on Render:
1. Go to: https://render.com
2. Click "Get Started" → Sign up with GitHub
3. Click "New +" → "Web Service"
4. Click "Connect a repository"
5. Select "chain-reaction-game"
6. Fill in:
   - Name: chain-reaction-game
   - Build Command: npm install
   - Start Command: npm start
7. Click "Create Web Service"
8. Wait 2-3 minutes

✅ Your game is live at: https://chain-reaction-game.onrender.com
